## One line to an interactive chart

Plotly has two interfaces. The low-level one builds charts from individual components, and the high-level one works like seaborn: a DataFrame, column names, and a grouping column.

```python
import plotly.express as px
import pandas as pd

df = pd.read_csv('penguins.csv')

fig = px.scatter(df, x='flipper_length_mm', y='body_mass_g', color='species')
fig.show()
```

An interactive scatter plot with three coloured groups, a legend you can click, and hover labels showing each point's coordinates.

The call structure is nearly identical to seaborn's, which makes the library easy to pick up: pass the data, name the columns, name the grouping column.

## The common arguments

| Argument | Does |
| ------------ | -------------------------------------- |
| `x`, `y` | Columns for the axes |
| `color` | Column to colour by |
| `size` | Column controlling marker size |
| `symbol` | Column controlling marker shape |
| `facet_col`, `facet_row` | Split into panels |
| `hover_data` | Extra columns to show on hover |
| `title` | The chart title |
| `labels` | A dictionary renaming axis labels |

`hover_data` is the one with no seaborn equivalent, and it is the reason to reach for Plotly at all:

```python
fig = px.scatter(df, x='flipper_length_mm', y='body_mass_g',
                 color='species', hover_data=['island', 'sex'])
```

Now hovering over a point reports its island and sex as well as its coordinates. The identification problem from the static scatter plot is solved without adding anything visible to the chart.

## What comes back

```python
type(fig)          # Figure
len(fig.data)      # 3
[t.name for t in fig.data]     # ['Adelie', 'Gentoo', 'Chinstrap']
```

A Plotly Figure, containing one trace per group. A trace is one set of drawn data, and the colour argument produced three of them.

That structure matters when you adjust the chart afterwards, because changes apply either to the layout as a whole or to individual traces.

## Adjusting after creation

```python
fig.update_layout(title='Body mass against flipper length',
                  xaxis_title='Flipper length (mm)',
                  yaxis_title='Body mass (g)',
                  width=800, height=500)

fig.update_traces(marker=dict(size=8, opacity=0.7))
```

`update_layout` changes the figure: titles, axes, size, legend position, margins. `update_traces` changes the drawn data: marker size, opacity, line width.

Those two methods cover most of what you will need. The naming is consistent enough that guessing usually works.

## The chart types

| Function | Draws |
| ------------------ | -------------------------------- |
| `px.scatter` | Points |
| `px.line` | Connected lines |
| `px.bar` | Bars |
| `px.histogram` | Binned counts |
| `px.box`, `px.violin` | Distribution by group |
| `px.imshow` | Heatmaps and images |
| `px.choropleth` | Values on a map |
| `px.sunburst`, `px.treemap` | Hierarchical proportions |

The first six mirror seaborn. The last three are where Plotly offers things seaborn does not.

## Faceting

```python
px.scatter(df, x='flipper_length_mm', y='body_mass_g',
           color='sex', facet_col='species')
```

Three panels, one per species, coloured by sex within each. The same small-multiples idea as seaborn's `col`, with the panels sharing zoom: dragging on one panel zooms them all, which is a real advantage when comparing.

## Showing and saving

```python
fig.show()                       # displays in a notebook or browser
fig.write_html('chart.html')     # a standalone file
fig.write_image('chart.png')     # a static image, needs kaleido installed
```

In a notebook `fig.show()` renders inline. In a script it opens a browser tab.

`write_image` requires an extra package and exists for the case where an interactive chart has to become a static one for a report. If that is the destination, seaborn was probably the better tool from the start.

> Plotly Express gets you to an interactive chart as fast as seaborn gets you to a static one. The decision is about the destination, not about the effort.

## Practise the hover

Take a scatter plot you built in seaborn and rebuild it with `px.scatter`.

Add three columns to `hover_data` that identify each point: an ID, a category, a date.

Then hover over the most extreme point in the chart. The information that would have taken a filter and a lookup appears immediately, which is the specific thing this library buys you.

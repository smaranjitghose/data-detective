## Several summaries in one pass

A single mean per group is rarely enough. You want the count, the spread, and the extremes together, because a mean without a count is not interpretable and a mean without a spread hides everything from the earlier units.

```python
import pandas as pd
df = pd.read_csv('penguins.csv')

df.groupby('species')['body_mass_g'].agg(['count', 'mean', 'std', 'min', 'max']).round(1)
```

```
           count    mean    std     min     max
species
Adelie       151  3700.7  458.6  2850.0  4775.0
Chinstrap     68  3733.1  384.3  2700.0  4800.0
Gentoo       123  5076.0  504.1  3950.0  6300.0
```

Five columns from one call, and now the earlier ANOVA result is readable directly. Adelie and Chinstrap means differ by 32 grams while both groups have standard deviations over 380, which is why no test found them different. Gentoos sit 1,350 grams above, with a minimum higher than either other species' mean.

## Named aggregations

Passing a list gives you the function names as columns. Naming them yourself gives a cleaner result and lets you aggregate different columns in the same call.

```python
df.groupby('species').agg(
    n=('body_mass_g', 'size'),
    mean_mass=('body_mass_g', 'mean'),
    max_flipper=('flipper_length_mm', 'max'),
    islands=('island', 'nunique')
).round(1)
```

```
             n  mean_mass  max_flipper  islands
species
Adelie     152     3700.7        210.0        3
Chinstrap   68     3733.1        212.0        1
Gentoo     124     5076.0        231.0        1
```

Each argument is `new_name=(column, function)`. The output columns are named as you asked, in the order you asked, with no hierarchical headers to unpick.

The `islands` column is doing real work here. Counting distinct islands per species reproduces the confound from the correlation unit in a single number: Adelies live on three islands, the other two on one each.

## A dictionary, for different functions per column

```python
df.groupby('species').agg({'body_mass_g': ['mean', 'std'],
                           'flipper_length_mm': 'median'}).round(1)
```

```
          body_mass_g        flipper_length_mm
                 mean    std            median
species
Adelie         3700.7  458.6             190.0
Chinstrap      3733.1  384.3             196.0
Gentoo         5076.0  504.1             216.0
```

This form produces a two-level column header, which is precise and awkward. Flattening it takes a line:

```python
result.columns = ['_'.join(c) for c in result.columns]
```

Named aggregation avoids the problem entirely, which is the main reason to prefer it.

## Which functions are available

| Function | Gives |
| ------------ | ------------------------------- |
| `'size'` | Rows in the group |
| `'count'` | Non-missing values |
| `'nunique'` | Distinct values |
| `'sum'`, `'mean'`, `'median'` | The usual summaries |
| `'std'`, `'var'` | Spread, with ddof=1 by default |
| `'min'`, `'max'` | Extremes |
| `'first'`, `'last'` | The first or last value in the group |

Note the `std` default here. pandas divides by n−1 while NumPy divides by n, which is the discrepancy from the NumPy unit showing up on the other side.

## Custom functions

```python
df.groupby('species')['body_mass_g'].agg(lambda s: s.max() - s.min())
```

```
Adelie       1925.0
Chinstrap    2100.0
Gentoo       2350.0
```

Any function taking a Series and returning one value works. This one computes the range, which has no built-in name.

The performance caution from the previous unit applies. A lambda runs once per group rather than once per row, so on a few dozen groups it costs nothing, and on a hundred thousand groups it is slow.

> Named aggregation with built-in function names is both the fastest and the most readable form. Reach for a lambda only when nothing built in expresses what you need.

## Quantiles inside a group

```python
df.groupby('species')['body_mass_g'].quantile([0.25, 0.5, 0.75])
```

This gives the quartiles per species, which is the five-number summary from the statistics unit computed per group. Combined with `min` and `max` from `agg`, it is everything a box plot would show, as numbers.

## Reading a grouped summary

The habit worth forming is to read the count column first, then the spread, and only then the mean.

A group of six rows with a standard deviation larger than its mean supports no conclusion, whatever the mean says. A group of 150 with a tight spread supports a firm one. The mean alone cannot tell those apart, and it is what people quote.

## Practise the full summary

Take any dataset with a grouping column.

Produce a named aggregation with at least five outputs: group size, non-missing count, mean, standard deviation, and one thing counted with `nunique`.

Then write two sentences about the result, one about the group that is best supported by its data and one about the group that is worst. If those two sentences would be identical from the means alone, the summary has done its job.

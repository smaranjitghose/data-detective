## One number per group, in one line

Almost every interesting question about a dataset is a question about groups. Average marks per department. Sales per city. Body mass per species.

```python
import pandas as pd
df = pd.read_csv('penguins.csv')
df.groupby('species')['body_mass_g'].mean().round(1)
```

```
species
Adelie       3700.7
Chinstrap    3733.1
Gentoo       5076.0
```

Three numbers that took several units of statistics to establish, produced by one line.

## What the line does

The pattern has a name: split, apply, combine.

pandas splits the rows into groups by the key you named, applies the operation to each group separately, and combines the results into a new object indexed by the group.

Understanding it as three steps explains everything else. You choose what to split on, what to apply, and the combining happens for you.

```python
df.groupby('species')          # split
           ['body_mass_g']     # which column to work on
                   .mean()     # apply
```

## Two keys give a hierarchical result

```python
df.groupby(['species', 'sex'])['body_mass_g'].mean().round(1)
```

```
species    sex
Adelie     female    3368.8
           male      4043.5
Chinstrap  female    3527.2
           male      3939.0
Gentoo     female    4679.7
           male      5484.8
```

Six groups from two keys. The result has a two-level index, which reads well and is awkward to work with further.

```python
df.groupby('species', as_index=False)['body_mass_g'].mean()
```

```
     species  body_mass_g
0     Adelie       3700.7
1  Chinstrap       3733.1
2     Gentoo       5076.0
```

`as_index=False` returns an ordinary DataFrame with the key as a column, which is usually what you want when the result feeds into something else. `.reset_index()` on the previous result does the same thing.

The sex breakdown is worth reading rather than skipping. Males are heavier than females in every species, and the gap between sexes within Gentoos is 805 grams, larger than the entire gap between Adelie and Chinstrap averages.

## count and size are not the same

```python
df.groupby('species').size()
df.groupby('species')['body_mass_g'].count()
```

```
           size  count
species
Adelie      152    151
Chinstrap    68     68
Gentoo      124    123
```

`size` counts rows. `count` counts non-missing values in the column.

The one-row differences for Adelie and Gentoo are the two birds with no measurements. Using `count` as a group size, on a column with gaps, undercounts silently.

> When you want the number of records, use `size`. When you want to know how many actually have a value, use `count`, and the difference between them is a missing-data report you got for free.

## Missing keys disappear by default

```python
df.groupby('sex', dropna=False).size()
```

```
female    165
male      168
NaN        11
```

Without `dropna=False`, the eleven birds with no recorded sex are dropped from the grouping entirely. They contribute to no group, appear in no row of the result, and nothing says so.

That silence matters when the group totals are supposed to add up to the file. Compare the sum of your group sizes against `len(df)` whenever the key might have gaps.

## transform keeps the original shape

`mean()` returns one row per group. `transform` returns one row per original row, with the group's value repeated.

```python
group_mean = df.groupby('species')['body_mass_g'].transform('mean')
df['dev'] = df['body_mass_g'] - group_mean
```

```
  species    mass  species_mean    dev
0  Adelie  3750.0        3700.7   49.3
1  Adelie  3800.0        3700.7   99.3
2  Adelie  3250.0        3700.7 -450.7
3  Adelie     NaN        3700.7    NaN
```

Each bird's mass against its own species average. This is how you standardise within groups, fill gaps with a group value, or flag rows that are unusual relative to their own group rather than to the file as a whole.

| Method | Returns | Use for |
| ------------ | -------------------- | ------------------------------- |
| `.mean()` | One row per group | A summary table |
| `.transform()` | One row per original row | A new column comparing each row to its group |
| `.filter()` | A subset of the original rows | Keeping or dropping whole groups |

## filter selects whole groups

```python
df.groupby('species').filter(lambda g: len(g) > 100)['species'].value_counts()
```

```
Adelie    152
Gentoo    124
```

Chinstraps are gone entirely, because that group has 68 rows. `filter` keeps or discards groups as units, which is how you drop categories too small to say anything about.

## Practise the three shapes

Take a dataset with a category column and a numeric column.

Produce three things: a summary table with one row per group, a new column giving each row its group's average, and a filtered dataset excluding groups with fewer than ten rows.

Then check `size` against `count` on your numeric column. Wherever they differ, you have found missing values you had not counted.

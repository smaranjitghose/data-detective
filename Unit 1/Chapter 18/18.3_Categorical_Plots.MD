## Comparing a measurement across groups

The comparison a bar chart of means makes badly is the one seaborn's categorical plots make well: how a numeric column differs across the values of a category.

```python
import seaborn as sns
import pandas as pd

df = pd.read_csv('penguins.csv')
sns.boxplot(df, x='species', y='body_mass_g')
```

Three boxes. Each shows the median as a line, the interquartile range as the box, whiskers extending to the furthest point within 1.5 interquartile ranges, and individual points beyond that.

Everything in that sentence comes from the outlier unit. A box plot is the fence method drawn, which is why two Chinstrap points appear outside their box and no points appear outside the Adelie or Gentoo boxes.

## The four plots and what each shows

| Function | Shows | Best for |
| -------------- | -------------------------------------- | ------------------------------- |
| `boxplot` | Median, quartiles, fences, outliers | Comparing many groups compactly |
| `violinplot` | The full smoothed distribution shape | Revealing multiple peaks |
| `stripplot` | Every individual point | Small samples, showing the raw data |
| `swarmplot` | Every point, spread to avoid overlap | Small samples, dense regions |
| `countplot` | How often each category occurs | Category frequencies |
| `barplot` | The mean, with a confidence interval | When one number per group is enough |

A box plot compresses a distribution into five numbers, which is its strength and its blind spot. Two groups with completely different shapes can produce identical boxes if their quartiles happen to match.

```python
sns.violinplot(df, x='species', y='body_mass_g')
```

A violin plot draws the smoothed density on both sides of the centre, so a group with two peaks looks like two bulges. The cost is the smoothing, with the same caveats as any density estimate.

## Showing the actual points

```python
sns.boxplot(df, x='species', y='body_mass_g', showfliers=False)
sns.stripplot(df, x='species', y='body_mass_g', size=3, alpha=0.5, color='black')
```

Drawing a box plot and then the individual points over it gives both the summary and the raw data. `showfliers=False` prevents the outliers being drawn twice.

This combination is worth defaulting to for small samples. With 68 Chinstraps, the points are informative; with 68,000 they would be a black block and the box alone is better.

## countplot for frequencies

```python
sns.countplot(df, x='species')
```

A bar chart of how many rows fall in each category: 152, 68, and 124. It is `value_counts` drawn, and it is the one categorical plot where the y axis is a count.

Adding `hue` splits each bar by a second category, which is the crosstab from the grouping unit rendered as grouped bars.

## barplot does something you should know about

```python
sns.barplot(df, x='species', y='body_mass_g')
```

This draws the mean of each group with a vertical line showing a 95% confidence interval, computed by bootstrapping.

Two things follow. The chart is making a statistical claim you did not explicitly request, and the interval is about the precision of the mean rather than the spread of the data.

Readers routinely misread those intervals as showing the range of the values, which is why a box plot is usually the better choice. If you want a bar of means, say in the caption what the error bars represent.

> A bar plot in seaborn is a mean with an inferential interval attached. A box plot is a description of the data as it is. They answer different questions and look similarly authoritative.

## Ordering

```python
sns.boxplot(df, x='species', y='body_mass_g',
            order=['Chinstrap', 'Adelie', 'Gentoo'])
```

Categories appear in the order they occur in the data unless you say otherwise. `order` fixes them, which matters when several charts must line up or when a natural sequence exists.

Sorting by the median, as the visualisation principles unit suggested, turns position into information.

## The figure-level version

```python
sns.catplot(df, x='species', y='body_mass_g', kind='box', col='sex')
```

`catplot` wraps all of these. `kind` selects which plot to draw, and `col` splits into panels, giving a box plot per species within each sex in one call.

## Practise the compression

Take a numeric column and a category with at least three values.

Draw a box plot, then a violin plot, then a box plot with points overlaid.

Compare what each reveals. On most real data at least one group will have a shape the box plot flattens, and finding it is the argument for looking at more than the five-number summary.

## A grid of numbers, coloured

When you have a table of values indexed by two categories, colour makes the pattern visible faster than reading the numbers does.

```python
import seaborn as sns
import pandas as pd

df = pd.read_csv('penguins.csv')
numeric = df.select_dtypes('number').drop(columns=['year'])
sns.heatmap(numeric.corr(), annot=True, fmt='.2f', cmap='coolwarm',
            vmin=-1, vmax=1, center=0)
```

The correlation matrix it draws:

```
                   bill_length  bill_depth  flipper  body_mass
bill_length              1.000      -0.235    0.656      0.595
bill_depth              -0.235       1.000   -0.584     -0.472
flipper                  0.656      -0.584    1.000      0.871
body_mass                0.595      -0.472    0.871      1.000
```

Sixteen numbers, four of which are the trivial diagonal. Coloured, the structure appears at a glance: one strongly red block where flipper length and body mass sit at 0.871, and a blue row where bill depth runs negative against everything else.

## The arguments that matter

| Argument | Does |
| -------- | ------------------------------------------- |
| `annot` | Prints the value in each cell |
| `fmt` | Number format for those values |
| `cmap` | Colour palette |
| `vmin`, `vmax` | Fix the colour scale's range |
| `center` | The value that maps to the palette's midpoint |

The last two are not cosmetic. Without `vmin=-1, vmax=1`, the colour scale stretches to whatever range your data happens to occupy, so a matrix whose strongest correlation is 0.3 will show that 0.3 in the same intense colour that 0.95 would get in another chart.

Two heatmaps drawn with automatic scales cannot be compared. Fixing the range makes them comparable, and for correlations the natural range is always −1 to 1.

## Diverging palettes for values with a midpoint

Correlations run from −1 to +1 with zero as a meaningful centre, which is exactly the case a diverging palette exists for. `coolwarm`, `RdBu`, and `vlag` put a neutral colour at the middle and two hues at the extremes.

Using a sequential palette here would show −0.9 and 0.0 as similar-looking pale colours and lose the sign entirely.

For a heatmap of counts or magnitudes, where zero is a floor rather than a midpoint, a sequential palette such as `viridis` is right and `center` should be left unset.

## The pooled matrix is misleading here

The bill length and depth cell reads −0.235. The correlation unit established what that hides:

```
                   bill_length  bill_depth  flipper  body_mass
bill_length              1.000       0.643    0.661      0.669
bill_depth               0.643       1.000    0.707      0.719
```

That is the same matrix computed within Gentoos alone. The bill relationship is +0.643 rather than −0.235, and every other correlation is different too.

A correlation heatmap of a file containing distinct groups is a heatmap of the groups as much as of the variables. Drawing one per group is more work and more honest.

> A correlation heatmap looks like a summary of the data. On grouped data it is a summary of the grouping, and nothing in the picture says so.

## Reading one properly

Three habits.

Ignore the diagonal, which is always 1 and always the most intense colour in the chart. `mask=np.triu(np.ones_like(corr, dtype=bool))` hides the upper triangle as well, since the matrix is symmetric and half of it is repetition.

Read the numbers, not just the colours. Colour intensity is a weak channel, and `annot=True` costs nothing.

And check the sample size behind the cells. A correlation computed on twelve rows and one on three hundred look identical in a heatmap.

## Heatmaps of other things

Correlation matrices are the common use and not the only one.

```python
counts = pd.crosstab(df['species'], df['island'])
sns.heatmap(counts, annot=True, fmt='d', cmap='Blues')
```

Any cross-tabulation works: counts by category pair, averages by month and region, activity by hour and day. The pivot tables from the grouping unit are heatmap input directly.

For a table with meaningful zeros, `fmt='d'` prints integers rather than decimals.

## Practise the group check

Take a numeric dataset with a category column.

Draw the correlation heatmap for the whole file, then for one group alone, with the same `vmin` and `vmax` so the colours are comparable.

Where a cell changes noticeably between the two, you have found a correlation that belongs to the grouping rather than to the variables, and it is the same finding the pooled bill measurements produce.

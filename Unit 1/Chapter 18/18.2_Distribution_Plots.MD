## Seeing the shape of one column

Seaborn has three functions for distributions, and choosing between them is a decision about how much smoothing you want.

```python
import seaborn as sns
import pandas as pd

df = pd.read_csv('penguins.csv')
sns.histplot(df, x='body_mass_g', bins=20)
```

The same histogram Matplotlib would draw, from a DataFrame and a column name, with the axis labelled from the column name automatically.

## Splitting by group

```python
sns.histplot(df, x='body_mass_g', hue='species')
```

One line replaces the loop from the Matplotlib unit. Three overlapping histograms appear in different colours, with a legend.

The default overlay makes overlapping regions hard to read. Two alternatives are worth knowing:

```python
sns.histplot(df, x='body_mass_g', hue='species', multiple='stack')
sns.histplot(df, x='body_mass_g', hue='species', element='step')
```

`stack` piles the groups so the total is the pooled distribution. `step` draws outlines only, which stays readable with three or four groups.

For the penguin masses, any of these shows the same structure: Adelie and Chinstrap sitting on top of each other from roughly 3,000 to 4,500 grams, Gentoo separated to the right.

## Kernel density estimates

```python
sns.kdeplot(df, x='body_mass_g', hue='species')
```

A kernel density estimate draws a smooth curve instead of bars. Each observation contributes a small bump, and the bumps are summed.

The advantage is that overlapping groups stay readable, since curves layer better than bars. The cost is that the smoothing is a choice you are making without seeing it.

| | Histogram | KDE |
| --------------- | -------------------------- | ---------------------------- |
| Shows | Actual counts per interval | A smoothed estimate |
| Free parameter | Bin count | Bandwidth |
| Boundaries | Honest at the edges | Spills past the data's range |
| Small samples | Noisy but truthful | Smooth and possibly invented |

The boundary problem is worth seeing once. A KDE of a quantity that cannot be negative, such as body mass, will show a curve extending below zero, because the smoothing does not know the values are bounded. Nothing in the chart flags it.

```python
sns.histplot(df, x='body_mass_g', kde=True)
```

Drawing both together is the safest option: the bars show what was measured and the curve shows the smoothed shape.

> A KDE is a model of your data, not a picture of it. On a few dozen observations it can show peaks that exist only in the smoothing.

## Empirical cumulative distributions

```python
sns.ecdfplot(df, x='body_mass_g', hue='species')
```

An ECDF plots, for each value, the proportion of observations at or below it. It rises from 0 to 1 and has no free parameter at all: no bins, no bandwidth.

That makes it the honest choice when you need to compare groups precisely. Reading a value off the curve gives a percentile directly, and two groups that differ show as two separated curves.

It is less intuitive for an audience unfamiliar with it, which is why it appears more in analysis than in reports.

## The figure-level version

```python
sns.displot(df, x='body_mass_g', col='species', bins=15)
```

`displot` is the figure-level equivalent. Instead of overlaying groups, `col` splits them into panels, which is the small-multiples layout from the Matplotlib unit in one argument.

```python
g = sns.displot(df, x='body_mass_g', col='species')
g.axes.shape        # (1, 3)
```

It returns a FacetGrid rather than an Axes, and the panels share axes by default, so the comparison is fair.

## Two variables at once

```python
sns.histplot(df, x='flipper_length_mm', y='body_mass_g')
```

Supplying both `x` and `y` gives a two-dimensional histogram, where colour shows the count in each cell.

This is the fix for overplotting in a scatter plot with tens of thousands of points, where individual markers merge into a block and density is invisible.

## Practise the smoothing question

Take a numeric column and draw it three ways: a histogram with 10 bins, a histogram with 40, and a KDE.

Note which features appear in all three. Then check whether the KDE extends past the actual minimum and maximum of your data.

If your column is bounded at zero and the curve crosses it, you have seen the main hazard of density estimates, and you will recognise it in published charts afterwards.

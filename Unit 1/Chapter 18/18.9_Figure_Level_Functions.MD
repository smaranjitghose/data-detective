## Three functions that build their own figure

Seaborn's plotting functions come in two kinds, and the distinction determines what you can do with the result.

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv('penguins.csv')

fig, ax = plt.subplots()
sns.histplot(df, x='body_mass_g', ax=ax)     # draws into your Axes

g = sns.displot(df, x='body_mass_g', col='species')
type(g)                                       # FacetGrid
```

Axes-level functions draw into an Axes you provide. Figure-level functions create the whole figure themselves and return a grid object.

## The three wrappers

| Figure-level | Wraps | `kind` options |
| ------------ | ---------------------- | ------------------------------------------- |
| `displot` | Distribution plots | `hist`, `kde`, `ecdf` |
| `catplot` | Categorical plots | `box`, `violin`, `strip`, `swarm`, `bar`, `count`, `point` |
| `relplot` | Relationship plots | `scatter`, `line` |

Each takes the same arguments as the axes-level function it wraps, plus `col`, `row`, and `col_wrap` for panels.

```python
sns.catplot(df, x='species', y='body_mass_g', kind='box', col='sex')
```

One call, two panels, a box plot per species in each.

## What you gain and what you give up

| | Axes-level | Figure-level |
| ------------------ | ------------------------- | ------------------------------ |
| Accepts `ax` | Yes | No |
| Can make panels | No | Yes, via `col` and `row` |
| Fits in a subplot grid you built | Yes | No |
| Returns | An Axes | A FacetGrid |
| Controls figure size | Through `plt.subplots` | Through `height` and `aspect` |

The trade is concrete. Figure-level functions give you faceting in one argument and cost you the ability to place the result inside a figure you are assembling.

If you are building a four-panel figure where each panel is a different kind of chart, you need axes-level functions and your own `plt.subplots`. If you want the same chart split across the values of a category, figure-level is one line.

> Trying to pass `ax` to `displot` and getting an error is the moment most people meet this distinction. The error means you want `histplot`.

## Sizing works differently

```python
sns.relplot(df, x='flipper_length_mm', y='body_mass_g',
            col='species', height=4, aspect=1.2)
```

Figure-level functions have no `figsize`. Instead, `height` sets the height of each panel in inches and `aspect` multiplies it for the width, so a panel here is 4 by 4.8 inches and the figure grows with the number of panels.

This is sensible once you accept the reason: the figure size depends on how many panels the data produces, which is not known until the function runs.

## Getting back to Matplotlib

```python
g = sns.relplot(df, x='flipper_length_mm', y='body_mass_g', col='species')
g.figure.suptitle('Mass against flipper length', y=1.03)
g.axes[0, 0].set_ylim(2500, 6500)
g.figure.savefig('out.png', dpi=200, bbox_inches='tight')
```

The grid exposes `figure` for the whole canvas and `axes` as an array for the individual panels. Everything from the Matplotlib unit applies through those handles.

`g.set(...)` applies a setting to every panel at once, which is usually what you want for shared limits or labels.

## Choosing between them

Use figure-level when you want panels, when the chart stands alone, and when you want seaborn to handle the layout.

Use axes-level when the chart is one panel of a figure you are composing, when you need precise control over the layout, or when you are mixing seaborn and Matplotlib in the same figure.

For exploratory work the figure-level functions win on brevity. For a final figure with several parts, building it yourself with axes-level calls is more predictable.

## Practise the failure

Create a figure with `plt.subplots(1, 2)` and try to draw a `displot` into the first Axes.

Read the error, then replace it with `histplot` and watch it work.

Then produce the same faceted output twice: once with `relplot` and `col`, and once by building the grid yourself with `plt.subplots` and looping `scatterplot` into each Axes. The line counts differ by about five, and knowing both routes means neither the wrapper's convenience nor its limitation can trap you.

## Controlling how a chart looks, once

Styling every chart individually is slow and produces inconsistency. Seaborn sets defaults for the whole session.

```python
import seaborn as sns
sns.set_theme(style='whitegrid', context='talk', palette='colorblind')
```

One call at the top of a notebook, and every chart afterwards follows it, including charts drawn with plain Matplotlib, because `set_theme` modifies Matplotlib's own defaults.

## The three arguments

| Argument | Controls | Options |
| --------- | ------------------------- | ---------------------------------------------- |
| `style` | Background and gridlines | `darkgrid`, `whitegrid`, `dark`, `white`, `ticks` |
| `context` | Size of text and elements | `paper`, `notebook`, `talk`, `poster` |
| `palette` | Default colours | `deep`, `colorblind`, `muted`, `pastel`, and others |

`context` is the one people miss. It scales fonts, line widths, and marker sizes together, so a chart built for a notebook can be made legible on a projector by changing one word rather than adjusting six settings.

A chart at `paper` context in a slide is unreadable from the third row. A chart at `talk` context in a dense report wastes space. Setting it per destination is faster than fixing font sizes one at a time.

## Palettes come in three kinds

The encoding unit established that colour does different jobs depending on the data, and seaborn's palettes divide the same way.

| Kind | For | Examples |
| ------------ | ------------------------------- | ----------------------------- |
| Qualitative | Unordered categories | `deep`, `colorblind`, `Set2` |
| Sequential | Ordered values, low to high | `viridis`, `Blues`, `rocket` |
| Diverging | Values around a midpoint | `coolwarm`, `vlag`, `RdBu` |

Using a sequential palette for species implies a ranking that does not exist. Using a qualitative palette for a correlation matrix destroys the ordering that is the whole point.

```python
sns.color_palette('colorblind').as_hex()[:3]
```

```
['#0173b2', '#de8f05', '#029e73']
```

Both `deep` and `colorblind` provide ten colours. The `colorblind` palette is designed so its colours remain distinguishable to readers with the common forms of colour vision deficiency, which is around one man in twelve.

There is no cost to using it as your default, and there is a real cost to red-and-green schemes in any audience of size.

## viridis and why it is a default elsewhere

`viridis` is a sequential palette designed so that its perceived brightness increases evenly across the range. That means equal steps in the data look like equal steps in the colour, which is not true of older schemes such as jet or rainbow.

It also converts to greyscale sensibly and remains readable to colour-blind viewers. For any chart where colour encodes a magnitude, it is a safe default.

> A rainbow palette on ordered data creates boundaries that are not in the data. The eye sees a band where yellow meets green and reads it as a threshold.

## How many colours

Beyond about seven categories, readers cannot match colours to a legend reliably.

When you have more, the options are to group the small categories into an "other" bucket, to use panels instead of colour, or to colour only the two or three categories being discussed and leave the rest grey. That last technique is the most effective in reports and the least used.

## Overriding per chart

```python
sns.boxplot(df, x='species', y='body_mass_g', palette='muted')
```

The `palette` argument on an individual call overrides the theme for that chart. Useful for the one chart that needs different treatment, and worth avoiding as a habit, since inconsistent colour across a report makes readers look for meaning in the difference.

If a category has a colour in one chart, it should have the same colour in every chart. Fixing that explicitly is worth it:

```python
colours = {'Adelie': '#0173b2', 'Chinstrap': '#de8f05', 'Gentoo': '#029e73'}
sns.scatterplot(df, x='flipper_length_mm', y='body_mass_g',
                hue='species', palette=colours)
```

## Resetting

```python
sns.set_theme()          # back to seaborn defaults
import matplotlib.pyplot as plt
plt.rcdefaults()         # back to plain Matplotlib
```

Worth knowing because `set_theme` changes global state, and a chart that looks different from yesterday's usually means a theme call ran in between.

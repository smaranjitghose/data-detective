## Two numeric columns, with grouping built in

```python
import seaborn as sns
import pandas as pd

df = pd.read_csv('penguins.csv')
sns.scatterplot(df, x='flipper_length_mm', y='body_mass_g', hue='species')
```

The chart from the Matplotlib unit, in one line instead of a loop, with a legend generated automatically.

The same finding appears: two clusters rather than one band, with Adelies and Chinstraps overlapping in the lower left and Gentoos separated in the upper right.

## Encoding more variables

```python
sns.scatterplot(df, x='flipper_length_mm', y='body_mass_g',
                hue='species', style='sex', size='bill_length_mm')
```

Three additional variables on three channels: colour, marker shape, and size.

Just because it is possible does not make it wise. The encoding unit ranked these channels, and size sits near the bottom. Two extra variables is usually the limit before a chart stops being readable, and panels are better than a third.

## Adding a fitted line

```python
sns.regplot(df, x='flipper_length_mm', y='body_mass_g')
```

`regplot` draws the scatter with a fitted straight line and a shaded band showing the uncertainty in that line.

For these two columns the overall correlation is 0.871, and the line slopes clearly upward. Fitting within species gives a different picture:

| Group | Correlation |
| --------- | ----------: |
| All birds | +0.871 |
| Adelie | +0.468 |
| Chinstrap | +0.642 |
| Gentoo | +0.703 |

Every within-species correlation is weaker than the pooled one. The pooled figure is partly measuring the gap between species rather than the relationship inside them, which is the same lesson the bill measurements taught in a more dramatic form.

```python
sns.lmplot(df, x='flipper_length_mm', y='body_mass_g', hue='species')
```

`lmplot` is the figure-level version and fits one line per group when given `hue`. Three lines appear, each shallower than the single pooled line would be.

> A regression line through pooled groups describes the arrangement of the groups as much as any relationship within them. Fitting by group is one argument, and it changes the answer.

## Lines for ordered data

```python
a = pd.read_csv('aapl.csv', parse_dates=['Date'])
sns.lineplot(a, x='Date', y='AAPL.Close')
```

`lineplot` connects points in x order, and it sorts the data first, which `plt.plot` does not. That alone prevents the scribble that unsorted dates produce.

It also does something worth understanding: when several y values share an x value, it plots the mean and draws a confidence band around it. On data with one observation per x that never appears. On data with repeats, a band appears that you did not ask for, and it is an aggregate rather than the raw values.

```python
sns.lineplot(data, x='month', y='sales', estimator=None)
```

Setting `estimator=None` turns the aggregation off and draws every point.

## Choosing among the three

| Function | Draws | Aggregates? |
| -------------- | ------------------------------ | ---------------------------- |
| `scatterplot` | Points only | No |
| `regplot` | Points plus a fitted line | No, but fits a model |
| `lineplot` | Connected line | Yes, when x values repeat |

`relplot` is the figure-level wrapper for the first and third, with `kind='scatter'` or `kind='line'`, and it adds `col` and `row` for panels.

## What the fitted line is not

The shaded band around a regression line shows uncertainty about the line's position, given the data and the assumption that the relationship is straight.

It does not show where future observations would fall, and it does not validate the straight-line assumption. A curved relationship gets a straight line fitted through it with a narrow band and no complaint, which is the situation the correlation unit warned about.

Look at the points before believing the line.

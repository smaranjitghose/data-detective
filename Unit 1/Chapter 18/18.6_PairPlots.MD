## Every pair of columns at once

A dataset with five numeric columns has ten possible pairs. Drawing them one at a time is slow, and the first look at an unfamiliar file wants all of them.

```python
import seaborn as sns
import pandas as pd

df = pd.read_csv('penguins.csv')
sns.pairplot(df, hue='species')
```

```
grid shape: (5, 5)
```

A grid with one row and column per numeric variable. Off-diagonal cells hold scatter plots of the pair; diagonal cells hold the distribution of that single variable, since a variable against itself would be a useless straight line.

With `hue='species'` every point is coloured by species, so group structure appears in every panel at once.

## What the penguin grid shows

Four measurements plus `year` gives a 5 by 5 grid, and the `year` row is immediately visible as a mistake: it produces three vertical stripes rather than a cloud, because it is a label stored as a number.

```python
sns.pairplot(df[['bill_length_mm', 'bill_depth_mm',
                 'flipper_length_mm', 'body_mass_g', 'species']], hue='species')
```

Restricting to genuine measurements gives a 4 by 4 grid, and three findings the course has established separately appear together.

The flipper and mass panel shows a tight upward relationship with the Gentoos separated in the upper right. The bill length and depth panel shows the reversal: three tilted clouds each sloping upward, arranged so that the overall pattern slopes down. And the diagonal shows the bimodality in mass and flipper length, with Gentoos forming the second hump.

Every one of those took a separate analysis earlier. The grid shows all of them in one call.

## Controlling what is drawn

| Argument | Does |
| ---------------- | ------------------------------------------- |
| `vars` | Which columns to include |
| `hue` | Colour by a category |
| `diag_kind` | `hist` or `kde` on the diagonal |
| `kind` | `scatter`, `reg`, `kde`, or `hist` off-diagonal |
| `corner=True` | Draw only the lower triangle |
| `plot_kws` | Options passed to the individual plots |

```python
sns.pairplot(df, vars=['bill_length_mm', 'body_mass_g'], hue='species',
             corner=True, plot_kws={'alpha': 0.6, 's': 20})
```

`corner=True` is worth using by default. The grid is symmetric, so the upper triangle repeats the lower with the axes swapped, and removing it halves the ink for no loss.

## The limits

Pair plots scale badly in two directions.

The number of panels grows with the square of the columns. Six columns give 36 panels, ten give 100, and each panel becomes too small to read. Beyond about six variables, select the ones your question involves rather than plotting everything.

And each panel holds every row, so overplotting arrives sooner than in a single chart. On tens of thousands of rows, set a low `alpha` or sample before plotting.

Generating a pair plot is also slow on large data, since it draws every panel independently.

> A pair plot is an exploratory instrument. It answers "what is in here" quickly and belongs in a report almost never, because a reader cannot be asked to interpret twenty panels.

## PairGrid, for control

```python
g = sns.PairGrid(df, hue='species')
g.map_upper(sns.scatterplot)
g.map_lower(sns.kdeplot)
g.map_diag(sns.histplot)
g.add_legend()
```

`pairplot` is a convenience wrapper around `PairGrid`, which lets you decide what goes in each region. Scatter above, density below, histograms on the diagonal is a common arrangement, and any seaborn function can be mapped.

Use it when the default is close but not right. Reach for it rarely, since the default covers most exploratory needs.

## What to look for

The grid rewards a systematic scan rather than a glance.

Read the diagonal first, for shape and multiple peaks. Then look for panels where the coloured groups separate cleanly, since those are the variables that distinguish your groups. Then look for panels where the group clouds tilt differently from the overall arrangement, which is the reversal pattern. And note any panel showing stripes or a hard edge, which means a variable is not what you assumed.

## A statistical layer on top of the plotting library

Drawing three overlaid histograms in Matplotlib means looping over the groups, calling `hist` once per group, setting transparency, collecting labels, and calling `legend`. Around eight lines.

```python
import seaborn as sns
import pandas as pd

df = pd.read_csv('penguins.csv')
sns.histplot(df, x='body_mass_g', hue='species')
```

One line, and the result is better looking than the default Matplotlib version.

Seaborn is not a replacement for Matplotlib. It calls Matplotlib underneath, returns Matplotlib objects, and everything from the previous unit still applies to what it produces.

## What it adds

| Feature | What it means |
| ----------------------- | ------------------------------------------------ |
| DataFrame awareness | Pass a table and column names, not arrays |
| Grouping by a column | `hue`, `col`, and `row` split the data for you |
| Statistical defaults | Aggregation, error bars, and density estimates built in |
| Sensible styling | Readable colours and spacing without configuration |
| Compound plots | Pair plots and grids in one call |

The first two are the practical wins. Matplotlib takes arrays of numbers and knows nothing about your table, so every grouping is a loop you write. Seaborn takes the DataFrame and the name of a grouping column.

## The pattern of every call

```python
sns.something(data, x='column', y='column', hue='column')
```

| Argument | Does |
| -------- | ------------------------------------- |
| `data` | The DataFrame |
| `x`, `y` | Column names for the axes |
| `hue` | Column to split by colour |
| `col`, `row` | Column to split into panels |
| `ax` | An existing Axes to draw into |

Learning that pattern once covers most of the library. The differences between `histplot`, `boxplot`, and `scatterplot` are what they draw, not how you call them.

## Two kinds of function

This distinction causes more confusion than anything else in seaborn, and it is worth establishing before you meet it by accident.

```python
fig, ax = plt.subplots()
sns.histplot(df, x='body_mass_g', ax=ax)     # returns an Axes
```

```python
g = sns.displot(df, x='body_mass_g', col='species')
type(g)          # FacetGrid
g.axes.shape     # (1, 3)
```

Axes-level functions draw into one Axes, accept an `ax` argument, and fit inside a Matplotlib figure you built. `histplot`, `boxplot`, and `scatterplot` are of this kind.

Figure-level functions create and own their whole figure, cannot take an `ax`, and can split into panels. `displot`, `catplot`, and `relplot` are of this kind, and they return a grid object rather than an Axes.

> If a seaborn function refuses your `ax` argument, it is a figure-level function and it wants to build the figure itself.

## It returns Matplotlib objects

```python
ax = sns.boxplot(df, x='species', y='body_mass_g')
ax.set_title('Body mass by species')
ax.set_ylim(0, 6500)
```

The return value is an ordinary Matplotlib Axes, so every method from the previous unit works on it: titles, limits, tick formatting, annotations.

This is the main reason learning Matplotlib first pays off. Seaborn gets you to a reasonable chart in one line; Matplotlib is how you finish it.

## What it does not do

Seaborn covers statistical charts of tables. It does not do interactive charts, maps, network diagrams, or anything three-dimensional, and it is not intended to.

It also makes decisions on your behalf. A bar plot in seaborn shows the mean with a confidence interval by default, which is usually helpful and is a statistical choice you did not explicitly make. Knowing what the default is doing is part of using the library honestly.

## Practise the translation

Take a chart you built in Matplotlib with a loop over groups.

Rewrite it as a single seaborn call using `hue`, and compare the two for length and appearance.

Then take the returned Axes and apply three Matplotlib adjustments to it: a title stating the finding, a zero baseline if it is a bar chart, and a formatted axis label. That combination, seaborn for the drawing and Matplotlib for the finishing, is how most working charts get made.

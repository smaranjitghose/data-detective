## One chart, repeated across groups

Colouring by a category works for two or three groups. Beyond that the colours overlap and the chart becomes unreadable, and the answer is to draw the same chart once per group.

```python
import seaborn as sns
import pandas as pd

df = pd.read_csv('penguins.csv')

g = sns.FacetGrid(df, col='species', row='sex')
g.map_dataframe(sns.scatterplot, x='flipper_length_mm', y='body_mass_g')
g.add_legend()
```

```
axes shape: (2, 3)
```

Six panels: three species across, two sexes down. Each shows the same scatter plot for one combination, on shared axes.

The layout is the small multiples pattern from the Matplotlib unit, produced by naming the splitting columns instead of writing a loop.

## How it works

`FacetGrid` creates the grid of empty Axes. `map` or `map_dataframe` draws the same plotting function into each one, with that panel's subset of the data.

| Argument | Does |
| -------- | ------------------------------------- |
| `col` | Column defining the panels across |
| `row` | Column defining the panels down |
| `hue` | Colour within each panel |
| `col_wrap` | Wrap a single row after N panels |
| `sharex`, `sharey` | Shared scales, both true by default |
| `height`, `aspect` | Size of each panel |

Shared axes being the default matters. Panels drawn on independent scales cannot be compared, and comparison is the entire purpose of the layout.

## col_wrap for many categories

```python
g = sns.FacetGrid(df, col='island', col_wrap=2)
```

With one splitting variable and many values, a single row of panels becomes too wide. `col_wrap` breaks it into a grid after the given number of columns.

This is the layout for a dozen regions, months, or product lines: a readable block of small panels rather than a horizontal strip.

## Figure-level functions do this for you

You will rarely construct a `FacetGrid` directly, because `displot`, `catplot`, and `relplot` build one internally:

```python
sns.relplot(df, x='flipper_length_mm', y='body_mass_g',
            col='species', row='sex', kind='scatter')
```

That single call produces the same six panels. The figure-level functions are the ordinary route, and knowing that `FacetGrid` is underneath explains what they return and why they refuse an `ax` argument.

Construct the grid yourself when you need a plotting function the wrappers do not offer, or when you want different content in different panels.

## Adjusting after drawing

```python
g.set_axis_labels('Flipper length (mm)', 'Body mass (g)')
g.set_titles('{row_name}, {col_name}')
g.figure.suptitle('Mass against flipper length by species and sex', y=1.02)
g.figure.savefig('facets.png', dpi=200, bbox_inches='tight')
```

The grid object has its own methods for labels and titles, and `g.figure` gives the underlying Matplotlib Figure for anything else.

`set_titles` takes a template. The default prints the column name and value on every panel, which is repetitive; a shorter template usually reads better.

## Empty panels are informative

A grid of species by island produces nine panels, of which four are empty, because Chinstraps appear only on Dream and Gentoos only on Biscoe.

Those empty panels are the same finding the crosstab gave, drawn. A layout with holes in it is telling you the two variables are not independent, which is worth noticing rather than tidying away.

> When faceting produces empty panels, the two splitting variables are related. That is a finding about the data, not a defect in the chart.

## When faceting is wrong

Panels split the data, so the reader compares across panels rather than within one.

If the question is whether two groups overlap, or which is higher at a given point, they belong on the same Axes with colour. If the question is whether the shape or the relationship differs between groups, panels are better.

And every panel divides the sample. Six panels over 344 birds leaves an average of 57 per panel, and some combinations will hold too few rows to show anything. Checking the counts per facet before drawing prevents reading noise as structure.

## Practise the split

Take a relationship between two numeric columns and draw it three ways: pooled on one Axes, coloured by a category, and faceted by that same category.

Then count the rows per facet. Any panel with fewer than about twenty rows should be read with suspicion, and knowing which panels those are before interpreting the grid is the check that makes the layout trustworthy.

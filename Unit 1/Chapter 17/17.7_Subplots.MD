## Several plots in one figure

Comparing four groups by overlaying them on one Axes produces a mess. Drawing one small panel per group, with shared axes, lets the reader compare shapes directly.

```python
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv('penguins.csv')

fig, axes = plt.subplots(1, 3, figsize=(12, 4), sharey=True)

for ax, (species, group) in zip(axes, df.groupby('species')):
    ax.hist(group['body_mass_g'].dropna(), bins=12)
    ax.set_title(species)

axes[0].set_ylabel('Number of penguins')
fig.suptitle('Body mass distribution by species')
fig.tight_layout()
```

Three panels side by side, each showing one species' mass distribution against the same vertical scale. Adelie and Chinstrap look similar and sit left; Gentoo sits noticeably right.

## The shape of what comes back

```python
fig, axes = plt.subplots(2, 3)      # axes.shape is (2, 3)
fig, axes = plt.subplots(1, 2)      # axes.shape is (2,)
fig, ax = plt.subplots(1, 1)        # a single Axes, not an array
```

The return type changes with the arguments, which is a common source of confusion. One row gives a one-dimensional array, a grid gives a two-dimensional one, and a single plot gives a bare Axes.

`axes.flat` gives a one-dimensional view of any grid, which makes looping uniform:

```python
for ax, col in zip(axes.flat, columns):
    ax.hist(df[col].dropna())
```

Passing `squeeze=False` forces a two-dimensional array even for a single plot, which is useful in code that has to handle any layout.

## Shared axes

```python
fig, axes = plt.subplots(1, 3, sharey=True)
```

`sharey=True` gives every panel the same vertical scale, and `sharex=True` does the same horizontally.

This is not cosmetic. Panels with independent scales cannot be compared, because a tall bar in one panel and a tall bar in another may represent completely different values. Any figure whose purpose is comparison needs shared axes on the compared dimension.

Sharing also removes the repeated tick labels from inner panels, which is why only the leftmost panel needs a y label.

## Small multiples

The pattern above has a name: small multiples. One chart repeated across the values of a categorical variable, with everything else held constant.

It is the most reliable way to show a third variable. Colour on one chart works for two or three groups; small multiples work for a dozen, and the comparison stays honest because each panel is drawn the same way.

| Approach | Groups it handles | Comparison quality |
| ---------------- | ----------------- | ------------------------ |
| Overlaid, colour | 2 to 3 | Good, then cluttered |
| Small multiples | 3 to 20 | Consistent throughout |
| One chart, no split | 1 | The group difference is hidden |

## Layout

```python
fig.tight_layout()
```

Titles and labels overlap by default when panels are close together. `tight_layout()` adjusts the spacing to fit everything, and it is worth calling on any multi-panel figure.

`fig.suptitle()` sets a title for the whole figure, distinct from each Axes title. With `tight_layout`, add `rect=[0, 0, 1, 0.95]` to leave room for it.

For unequal panel sizes, `plt.subplot_mosaic` lets you describe the layout as a small text diagram, which is easier to read than the older grid specifications.

## Empty panels

A grid of six panels holding five plots leaves one empty box with axes drawn on it, which looks like an error.

```python
for ax in axes.flat[len(items):]:
    ax.set_visible(False)
```

Hiding the unused Axes removes it cleanly.

> Two panels on one figure make a comparison. Twelve panels with different scales make a wall, and the reader will take the impression of thoroughness rather than any specific finding.

## When one chart is better

Small multiples split the data, which means the reader compares across panels rather than within one.

If the question is whether two series cross, or which is higher at a given moment, they belong on the same Axes. If the question is whether the shapes differ, panels are better.

Deciding which question you are asking, before choosing the layout, is the whole of it.

## Practise the grid

Take a dataset with a categorical column of four or more values.

Draw one histogram per category as a grid of small multiples, with `sharex` and `sharey` both true.

Then redraw with sharing turned off and compare. The second version will look reasonable and support no comparison at all, which is the fastest way to see why shared axes matter.

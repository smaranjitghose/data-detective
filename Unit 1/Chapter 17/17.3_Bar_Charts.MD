## Comparing values across categories

A bar chart encodes each value as a length from a common baseline. That is the most accurately read arrangement available, which is why it is the default for comparing categories.

```python
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv('penguins.csv')
means = df.groupby('species')['body_mass_g'].mean()

fig, ax = plt.subplots(figsize=(6, 4))
ax.bar(means.index, means.values)
ax.set_ylim(0, 6000)
ax.set_ylabel('Mean body mass (g)')
```

Three bars at 3,701, 3,733, and 5,076 grams. The first two are nearly the same height and the third is visibly taller, which is the correct impression.

## The zero baseline is not optional

`ax.set_ylim(0, 6000)` appears in that code deliberately. Without it, Matplotlib chooses limits that frame the data attractively, which for these three values means starting somewhere above 3,000.

The arithmetic from the visualisation principles unit applies directly. The true height ratio between the Gentoo bar and the Adelie bar is 1.37. With the axis starting at 3,600 it becomes 14.61.

The library will do that to you by default and without comment. Setting the lower limit to zero on every bar chart is the fix, and it takes one line.

## Horizontal bars for long labels

```python
ax.barh(means.index, means.values)
```

`barh` swaps the axes. Category names run along the vertical axis, where there is room for them, instead of being rotated or truncated along the horizontal.

Use horizontal bars whenever labels are longer than about eight characters or there are more than about eight categories. Rotated labels are readable and slow to read, and slow is the same as unread in a report.

## Sorting is part of the chart

```python
means.sort_values().plot(kind='barh', ax=ax)
```

Categories have no natural order, so whatever order you leave them in is a choice. Alphabetical is a default, not a neutral one.

Sorting by value turns position into information: the reader sees the ranking immediately instead of reconstructing it by comparing heights. The exception is a category with a real order, such as a rating scale or a sequence of years, where the natural order should be preserved.

## Grouped bars

```python
grouped = df.pivot_table(values='body_mass_g', index='species', columns='sex', aggfunc='mean')

x = range(len(grouped))
width = 0.35
ax.bar([i - width/2 for i in x], grouped['female'], width, label='female')
ax.bar([i + width/2 for i in x], grouped['male'], width, label='male')
ax.set_xticks(list(x))
ax.set_xticklabels(grouped.index)
ax.legend()
```

Six bars in three pairs, showing female and male means per species. The arithmetic with `width` places the two sets side by side rather than on top of each other.

The result makes the comparison from the grouping unit visible: males above females in all three species, and the gap within Gentoos larger than the gap between the two smaller species.

## Grouped or stacked

| | Grouped | Stacked |
| ------------------- | ------------------------- | ------------------------------- |
| Compares | Categories within a group | Totals across groups |
| Baseline | Shared, for every bar | Only for the bottom segment |
| Works with | Two to four sub-categories | Two, or a total plus one part |
| Fails when | Many sub-categories | Comparing anything but the bottom |

Stacked bars beyond two segments are hard to read for the reason the encoding unit gave: only the bottom segment starts at a common baseline, so the others cannot be compared across bars.

Use stacking when the total is the point and the parts are secondary. Use grouping when the parts are the point.

## Error bars, when the mean is uncertain

```python
errors = df.groupby('species')['body_mass_g'].std()
ax.bar(means.index, means.values, yerr=errors, capsize=4)
```

A plain bar of a mean implies a precision it does not have. Adding the standard deviation as an error bar shows the spread, and for these species it shows immediately that the Adelie and Chinstrap ranges overlap almost entirely.

> A bar chart of three means is three numbers. The same chart with error bars is three numbers and the reason two of them cannot be told apart.

State what the bars represent in the caption, since a standard deviation, a standard error, and a confidence interval look identical on a chart and mean different things.

## Practise the baseline

Take three group means and draw them twice: once with `set_ylim(0, ...)` and once with the default limits.

Measure the apparent ratio between the tallest and shortest bar in each version and compare it against the true ratio in the data.

Then add error bars to the honest version. The two changes together turn a chart that overstates a difference into one that shows how large the difference is and how confident you should be about it.

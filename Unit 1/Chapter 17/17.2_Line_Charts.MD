## Showing change along a continuous axis

A line chart connects points in order, and the connection is a claim: that the space between two points is meaningful and that values in between would fall along the line.

That claim is true for time, for distance, for temperature. It is false for categories, which is why a line chart of departments or species is a mistake regardless of how it looks.

```python
import matplotlib.pyplot as plt
import pandas as pd

a = pd.read_csv('aapl.csv', parse_dates=['Date'])

fig, ax = plt.subplots(figsize=(9, 4))
ax.plot(a['Date'], a['AAPL.Close'])
ax.set_title('Apple closing price, Feb 2015 to Feb 2017')
ax.set_ylabel('Closing price (USD)')
```

What appears is 506 trading days of closing prices, running from about 128 at the left, falling through the second half of 2015 to a low near 90 in mid-2016, then climbing back above 130 by early 2017. The full range in the data is 90.34 to 135.51.

The dates on the horizontal axis are formatted automatically because the column is a datetime rather than text, which is one of the practical rewards for parsing dates properly at load.

## Several series

```python
ax.plot(a['Date'], a['AAPL.Close'], label='Close')
ax.plot(a['Date'], a['mavg'], label='30-day average')
ax.legend()
```

Each `plot` call adds a line to the same Axes. Colours cycle automatically, and the legend appears only when you call for it and only for lines you labelled.

Beyond about five lines a chart becomes unreadable, and the usual repair is to emphasise one series and grey the rest, or to split into small multiples.

## The parameters worth knowing

| Parameter | Controls | Example |
| ----------- | ------------------- | ------------------------ |
| `color` | Line colour | `color='steelblue'` |
| `linewidth` | Thickness | `linewidth=2` |
| `linestyle` | Solid, dashed, dotted | `linestyle='--'` |
| `marker` | Point markers | `marker='o'` |
| `alpha` | Transparency | `alpha=0.5` |
| `label` | Legend text | `label='Close'` |

Line style deserves more use than it gets. Distinguishing series by colour alone fails in greyscale printing and for readers with colour vision deficiency, and adding a dashed style costs nothing.

Markers are worth adding when the data has few points, since a line through twelve monthly values hides where the measurements actually are. On 506 points they turn the line into a smear.

## Gaps in the data

Matplotlib draws a break where a value is missing, which is correct: it declines to interpolate across a gap it knows nothing about.

That behaviour is useful and it depends on the gap being represented as a missing value. A file where absent days are simply absent, rather than present with a missing value, will be drawn as a continuous line straight across the gap, implying data that does not exist.

Reindexing to a complete date range before plotting makes the gaps visible:

```python
full = a.set_index('Date').reindex(pd.date_range(a['Date'].min(), a['Date'].max()))
```

For this dataset that inserts weekends as missing values, and the line breaks every few days, which is honest and ugly. Whether you want it depends on whether the absence is meaningful.

> A line chart's most dangerous property is that it will connect any two points you give it, including points separated by a gap where everything happened.

## Ordering matters

`plot` connects points in the order they appear in the data, not in sorted order.

An unsorted date column produces a line that jumps backwards and forwards across the chart, which looks like a scribble and is often the first sign that the data was never sorted.

```python
a = a.sort_values('Date')
```

Sort before plotting anything against a continuous axis.

## When not to use a line

| Situation | Use instead |
| ---------------------------------- | ------------------------ |
| Categories on the x axis | Bar chart |
| Two variables with no natural order | Scatter plot |
| A single distribution | Histogram |
| Very few points and no continuity | Bar chart or a table |

The first row is the common error. Connecting the mean body mass of three species with a line implies that something lies between Adelie and Chinstrap, and nothing does.

## Practise the gap

Take any time series and plot it as it comes.

Then remove a fortnight of rows from the middle, plot again, and observe that the line simply carries on across the missing period with no indication anything is absent.

Then reindex to the full date range so the gap becomes missing values, and plot a third time. The three charts show the same data, and only one of them tells the truth about what was measured.

## Counting the gaps, then asking why they are there

```python
import pandas as pd
df = pd.read_csv('penguins.csv')
df.isna().sum()
```

```
species               0
island                0
bill_length_mm        2
bill_depth_mm         2
flipper_length_mm     2
body_mass_g           2
sex                  11
year                  0
```

Thirteen gaps in a file of 344 rows. That is the easy part of the work. The hard part is what they mean, and the counts alone cannot tell you.

## The pattern is more informative than the count

Four columns each missing exactly two values suggests two rows missing everything, rather than gaps scattered independently. One line confirms it:

```python
df[df['body_mass_g'].isna()]
```

```
     species     island  bill_length_mm  bill_depth_mm  flipper_length_mm  body_mass_g  sex  year
3     Adelie  Torgersen             NaN            NaN                NaN          NaN  NaN  2007
271   Gentoo     Biscoe             NaN            NaN                NaN          NaN  NaN  2009
```

Two birds were recorded as sighted with no measurements taken at all. That is a different problem from a scale failing occasionally, and it calls for a different response.

```python
df.isna().any(axis=1).sum()      # 11
```

Only eleven rows are affected in total, because the two blank rows are also among the eleven missing sex.

## Do the missing rows differ from the rest?

This is the question that decides whether the gaps matter.

```python
df[df['sex'].isna()]['species'].value_counts()
```

```
Adelie    6
Gentoo    5
```

No Chinstraps at all. Chinstraps are 19.8% of the file, so seeing none among eleven missing rows is a little unusual but not remarkable at that sample size.

The check itself is the point. Compare the composition of the incomplete rows against the file overall, on every column you do have. If the gaps concentrate in one group, dropping them removes that group disproportionately.

> Whether missing data biases your results depends on why it is missing, and the file cannot answer that. What the file can show is whether the incomplete rows look like the complete ones.

## Dropping

```python
len(df.dropna())                          # 333
len(df.dropna(subset=['body_mass_g']))    # 342
len(df.dropna(how='all'))                 # 344
len(df.dropna(thresh=6))                  # 342
```

Four calls, four different results.

| Call | Drops | Keeps |
| ---------------------------- | -------------------------------- | ----: |
| `dropna()` | Any row with any missing value | 333 |
| `dropna(subset=['body_mass_g'])` | Rows missing that one column | 342 |
| `dropna(how='all')` | Only rows that are entirely empty | 344 |
| `dropna(thresh=6)` | Rows with fewer than 6 real values | 342 |

The default is the most aggressive, and it is what people reach for without thinking. Using it here to analyse body mass would discard nine birds whose mass was recorded perfectly well, purely because their sex was not.

Drop on the columns your analysis needs, not on everything.

## Filling, and what it does to the spread

```python
m = df['body_mass_g']
```

| Approach | Mean | Standard deviation |
| ------------------- | -------: | -----------------: |
| Leave the gaps | 4,201.75 | 801.95 |
| `fillna(0)` | 4,177.33 | 861.23 |
| `fillna(mean)` | 4,201.75 | 799.61 |
| Fill with species mean | 4,202.84 | 801.46 |

Filling with zero is the destructive option. Two birds now weigh nothing, which drags the mean down and inflates the spread, and both effects are invisible in any later summary.

Filling with the overall mean leaves the mean untouched by construction and shrinks the standard deviation, because two values now sit exactly at the centre. With two gaps in 342 the shrinkage is small. With 30% missing it would be severe, and every subsequent measure of spread would be understated.

Filling with the group mean is better where a grouping column exists. A missing Gentoo mass is better estimated by other Gentoos than by an average across three species of different sizes.

```python
df.groupby('species')['body_mass_g'].transform(lambda s: s.fillna(s.mean()))
```

## Choosing a response

| Situation | Response |
| ---------------------------------------- | ---------------------------------- |
| Few gaps, scattered, analysis needs the column | Drop those rows |
| Rows missing everything | Drop, and note them |
| Gaps concentrated in one group | Investigate before deciding anything |
| Time series with occasional gaps | Fill forward from the previous value |
| A grouping column that predicts the value | Fill with the group's value |
| Missingness that is itself informative | Add a flag column and keep the rows |

That last row deserves attention. A blank income field on a form may mean the respondent declined, which is information. Recording `income_missing` as a column before filling preserves it.

## What the placeholder might be

Gaps do not always arrive as blanks. Files use 999, -1, 0, "NA", "not recorded", "N/A", and empty strings, and pandas reads most of them as ordinary values.

Reading `value_counts()` on every column and the min and max of every numeric column is how you find them. An age column with a maximum of 999 has a placeholder, not a very old person.

## Practise the comparison

Take a file with missing values in at least one column.

Compare the rows with gaps against the rows without, on two or three other columns. Then compute a summary of the affected column three ways: dropping, filling with the mean, and filling with a group mean.

Report all three and note which decisions changed your answer. That is the finding, and it belongs in your write-up more than the cleaned number does.

## Checking an assumption before you rely on it

Several of the tests in this unit assume the data comes from a roughly normal distribution. That assumption is usually stated once and then forgotten, which is a problem, because when it fails the results are wrong without any warning appearing.

The Shapiro-Wilk test checks it. It takes a column of numbers and asks whether they look like a sample from a normal distribution.

## What it tests

The hypotheses are arranged in the direction people find confusing.

| | Statement |
| ----- | ------------------------------------------------ |
| $H_0$ | The data comes from a normally distributed population |
| $H_1$ | It does not |

Here the null hypothesis is the thing you usually hope is true. A large p-value means the data is consistent with normality, and a small one means it is not.

That reverses the usual reading. In most tests a small p-value is the exciting result. Here it is a warning.

The test statistic is $W$, which runs between 0 and 1. Values close to 1 indicate close agreement with a normal shape.

## Two columns from the same file

Run it on the flipper lengths of the 151 Adelie penguins alone:

```
W = 0.9934,  p = 0.72
```

A p-value of 0.72 is nowhere near any sensible threshold, so nothing about these measurements argues against normality. Methods assuming a normal shape are reasonable here.

Now run the same test on the flipper lengths of all 342 birds with a recorded measurement:

```
W = 0.9515,  p = 0.0000000035
```

Emphatically not normal. And the reason is one you already know: the file holds three species, Gentoos have much longer flippers, and pooling them produces two clusters rather than one bell.

> The pooled column failed the test not because the measurements are strange, but because the file contains groups that should be described separately. A normality failure is often a grouping problem in disguise.

## What to do when it fails

Four responses, roughly in order of preference.

Split by group first. If the failure comes from mixing populations, testing within each group is both more honest and more informative.

Use a method that does not assume normality. There are alternatives to most standard tests that work on ranks rather than values, and they cost a little sensitivity in exchange for making no shape assumption.

Rely on sample size. Tests about means lean on the central limit theorem rather than on the raw data being normal, and with reasonably large samples they tolerate non-normal data well. This is why a normality failure matters far more for a sample of 12 than for one of 300.

Transform the values. Taking logarithms of a right-skewed quantity often produces something much closer to normal, at the cost of changing what your results are about.

## The problem with the test itself

Shapiro-Wilk has an awkward property that follows directly from how all significance tests behave with sample size.

With small samples it has little power, so clearly non-normal data often passes. With large samples it has enormous power, so trivial and harmless departures from normality get flagged.

| Sample size | What the test tends to do |
| ----------- | ---------------------------------------------- |
| Under 20 | Passes almost anything, including clearly skewed data |
| 20 to 200 | Behaves usefully |
| Over 1,000 | Rejects nearly everything, including data that is fine to work with |

No real dataset is exactly normal, so with enough rows the test is guaranteed to reject eventually. This makes it a poor sole authority on whether to proceed.

The practical approach is to treat the p-value as one input rather than a verdict. Look at the shape of the distribution, compare the mean against the median, ask whether the quantity is bounded at zero, and use the test to confirm what you are already seeing.

## When normality actually matters

It matters most for small samples and for methods that use the shape directly.

| Situation | Does normality matter? |
| --------------------------------------- | --------------------------------------- |
| Comparing means, large samples | Barely, the central limit theorem covers it |
| Comparing means, samples under 20 | Yes, substantially |
| Prediction intervals for individual values | Yes, these use the shape directly |
| The empirical rule's 68-95-99.7 coverage | Yes, entirely |
| Describing data with a median and quartiles | No, these assume nothing |

The bottom row is worth noticing. Position-based summaries never needed the assumption in the first place, which is part of why they are the safe default in exploratory work.

## Practise on both versions of a column

Take any dataset with a numeric column and an obvious grouping column.

Test the numeric column for normality across the whole file, then test it separately within each group. Note whether the verdict changes.

If it does, you have found the same lesson the penguin flippers taught: the pooled distribution was describing a mixture, and the test was reporting the mixing rather than anything about the measurements themselves.
